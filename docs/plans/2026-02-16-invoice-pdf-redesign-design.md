# Invoice PDF Redesign

## Context

The monthly invoice PDF generated by `MonthlyInvoicePdfService` is a basic layout missing legally required fields for a Danish business entity. It also uses blue accents that don't match the app's monochrome design language.

## Business Entity

- **Company**: Mappso
- **Address**: Vilh. Bergsøes Vej 11, 8210 Aarhus V, Denmark
- **CVR**: 42149705
- **VAT Status**: Not VAT registered

## Design

### Layout

A4, white background, monochrome (black text, gray accents). No decorative elements.

**Header**: "INVOICE" title (left), company details (right)
**Billing section**: Bill-to email, invoice number, issue date, service period
**Line items table**: Description + Amount, clean minimal table
**Summary**: Right-aligned subtotal/total
**Footer**: VAT status note, company info, generation timestamp

### Danish Legal Requirements

1. Invoice number - `INV-YYYY-MM` derived from period
2. Date of issue
3. Seller name, address, CVR
4. Buyer identification (email)
5. Service descriptions
6. Service period
7. Line amounts and total
8. VAT status: "Not VAT registered (Ikke momsregistreret)"
9. Currency on all amounts

## Scope

- Rewrite `MonthlyInvoicePdfService.cs` only
- No new dependencies, no DB changes, no frontend changes
